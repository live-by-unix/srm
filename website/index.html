Safe RM

Move files to Trash instead of permanently deleting them

srm is a cross-platform alternative to rm that provides a safety layer by moving files to the native Trash or Recycle Bin. Recoverable, familiar, and safe.

Install srm Try Demo
Terminal
$ srm document.txt
$ srm -r old-project/
$ srm -v *.log srm: moved 'error.log' to Trash

rm vs srm

rm

  • Permanently deletes files
  • Cannot recover files
  • Dangerous mistakes permanent
  • Fast and efficient
  • Standard Unix tool

srm

  • Moves to Trash/Recycle Bin
  • Files are recoverable
  • Mistakes can be undone
  • rm-compatible interface
  • Cross-platform support

Features

🗑️

Native Trash Integration

Uses the operating system's actual Trash or Recycle Bin on macOS, Linux, and Windows.

💻

Cross-Platform

Works on macOS, Linux, and Windows with consistent behavior across platforms.

🔄

rm Compatible

Familiar command-line interface with support for common options like -r, -f, -v.

🔒

Safe by Default

Never silently falls back to permanent deletion. Always reports errors.

📁

Recursive Safe

Directories are moved to Trash as recoverable units, not deleted file-by-file.

🛡️

Root Protection

Protects against dangerous operations on root and home directories by default.

Platform Support

macOS

Uses NSFileManager API for native Finder Trash integration.

Supported

Linux

Implements FreeDesktop.org Trash specification for GNOME, KDE, XFCE.

Supported

Windows

Uses IFileOperation API for actual Recycle Bin integration.

Supported

Available Commands

  • srm <file> - Move file to Trash
  • srm -r <dir> - Move directory to Trash recursively
  • srm -v <file> - Verbose output
  • srm -f <file> - Force mode (ignore missing files)
  • ls - List files
  • srmi --help - Show help
  • restore <file> - Restore from Trash
  • clear - Clear terminal

Installation

# Clone the repository
git clone https://github.com/live-by-unix/srm.git
cd srm

# Build the native helper
cd src
./build-macos.sh
cd ..

# Install
./scripts/install.sh

# Add to PATH (add to ~/.zshrc or ~/.bashrc)
export PATH="$HOME/bin:$PATH"
# Clone the repository
git clone https://github.com/live-by-unix/srm.git
cd srm

# Install (no build required for Linux)
./scripts/install.sh

# Add to PATH (add to ~/.bashrc or ~/.zshrc)
export PATH="$HOME/bin:$PATH"
# Clone the repository
git clone https://github.com/live-by-unix/srm.git
cd srm

# Build the native helper (requires Visual Studio)
cd src
build-windows.bat
cd ..

# Install
scripts\install.bat

# Add to PATH via System Properties > Environment Variables
